# Paygoo

A self-payment mobile application that lets you pay the bill directly from your phone.

## About

Paygoo is a native mobile application built with Flutter and Dart, designed to simplify the bill payment experience. Whether you're dining out with friends or splitting expenses, Paygoo makes it easy to handle payments seamlessly.

## Features

- **Pay Full Bill** - Settle the entire bill in one go
- **Pay Your Part** - Pay only your portion of the bill
- **Split the Bill** - Easily divide expenses among multiple people

## Tech Stack

- **Language**: Dart
- **Framework**: Flutter
- **Platforms**: iOS, Android
